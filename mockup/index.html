A benchmark score is a poll, not a fact. See which wins survive the margin of error.

The gaps, up close

Each bar is the plausible range for the true gap between the models. If a bar touches the zero line, the “lead” could just be luck in which questions were asked.

How big must an eval be? find out before trusting a scoreboard

Every eval has a smallest gap it can reliably tell apart from luck. Set the gap you care about and see how many questions that takes.

Based on Miller, Adding Error Bars to Evals (Anthropic, 2024).

The method. Everything here follows the paper above. Click any dashed value in the app to see the exact formula and the section it comes from. The guided demo reproduces the paper’s worked example number for number.

The data. Real datasets are derived from the Open LLM Leaderboard archive — scores and group labels only, no benchmark questions or answers. The conversion script is in the repo.

Prior art. These statistics already exist as Python libraries: evalci, evalstats, Inspect AI’s stderr(), and Every Eval Ever. What was missing was a version you don’t have to install.

One correction. The paper’s Table 1 lists HumanEval/Dreadnought as 87.7%; we use 86.7%, which is what its own −3.1 difference implies and what its later tables use.
